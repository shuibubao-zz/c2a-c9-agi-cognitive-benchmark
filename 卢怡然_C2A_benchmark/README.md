> Track 2 — Metacognition（元认知）｜ Kaggle / DeepMind AGI Cognitive Abilities

## 一句话

让被测方对**数值量**给出 **90% 置信区间**，用 **Winkler 区间得分**（proper scoring rule）
同时评估它的**校准**（有没有盖住真值）、**锐度**（敢不敢下判断）与**辨别力**（是否知道自己何时不准）。

## 30 秒跑起来

```bash
cd 卢怡然_C2A_benchmark
python harness.py selftest     # 9 个断言，全绿 = 评分内核没坏
python harness.py demo         # 模拟被试验证：4 个原型能否被指标区分开
python harness.py gen --n 60   # 生成题集（含真值版 + 无真值版）
```

零第三方依赖，Python 3.8+，只用标准库。

## 指标（三个是三件事，分开测）

| 指标 | 定义 | 抓什么失败模式 |
|---|---|---|
| **相对 Winkler 得分** ↓ | `(u−l) + (2/α)·偏离量`，按真值量级归一 | 主指标：同时罚"没盖住"和"不敢判断" |
| **覆盖率缺口** | 声称覆盖率 − 实际命中率（>0 过度自信） | 抓过度自信 |
| **锐度** | 相对半宽均值 | 抓"永远给超宽区间"的对冲 |
| **辨别力 ρ** | 区间宽度 vs 实际误差的 Spearman 相关 | 抓"不知道自己何时不准" |

### 为什么必须用 proper scoring rule（已实证）

模拟被试验证的真实输出（`evidence/simulated_validation.txt`）：

| 原型 | 命中率 | 覆盖率缺口 | 相对Winkler↓ | 辨别力ρ |
|---|---:|---:|---:|---:|
| calibrated | 0.92 | −0.024 | **0.623** | +0.773 |
| overconfident | 0.27 | **+0.627** | 1.652 | +0.811 |
| hedger（永远超宽） | **1.00** | −0.100 | **2.756** | +0.801 |
| uniform_width | 0.77 | +0.127 | 1.477 | **−0.055** |

**关键结论**：`hedger` 命中率 100%、覆盖率缺口为负——如果只看覆盖率，它看起来**最谦虚最好**；
但 Winkler 得分最差（2.756 vs 0.623），因为它的区间宽到毫无信息量。
**只看覆盖率会被套牢式对冲骗过；Winkler 不会。**

并且三个指标各抓一种失败模式：覆盖率缺口抓 overconfident，辨别力抓 uniform_width，
Winkler 抓 hedger——**缺一不可**，这就是"三维解耦"的实证依据。

## 真实试点（n=16）

对本机 Agent（WorkBuddy）跑了一次端到端试点（`evidence/pilot_run_combined.txt`）：

```
命中率 1.000 ｜ 覆盖率缺口 −0.100（偏保守）｜ 相对Winkler 0.309
锐度 0.155 ｜ 辨别力 ρ = +0.822 ｜ 平均相对绝对误差 0.077
```

诚实说明：
- n=16，**样本太小**，不足以得出任何关于模型元认知的结论
- 被测方是本机 Agent，**不是前沿模型**；用途是验证 harness 端到端可执行
- 污染对照落差为 +0.000（两侧都 100% 命中），**该指标在 n 太小且全命中时无法区分**——已知局限
